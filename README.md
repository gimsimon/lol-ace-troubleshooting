# 英雄联盟国服断连与 ACE 异常排查记录

为了正常玩一局英雄联盟，我做过游戏修复、重装、清理 DNS，也让 GPT 和 Codex 检查过 ACE、Windows 日志和代理配置。这个仓库记录遇到的问题、尝试过的办法和目前的排查结果，供遇到相似情况的人参考和交流。

**状态：尚未确认根因，也没有验证有效的最终解决方案。** 本仓库是个人案例记录。

## 遇到的问题

环境为 Windows 10，通过 WeGame 启动英雄联盟国服。此前长期正常，从 2026 年 10 月 16 日左右开始，游戏运行一段时间后反复提示“安全系统或数据被篡改”，并出现 5 分钟限制。

![英雄联盟账号连接已断开的提示](assets/account-disconnected.png)

> 这个账号的连接已断开，原因可能是：1. 网络连接不稳定。2. 账号正在进行转区操作 3. 账号行为因违反规定被冻结，您可以通过腾讯游戏安全中心微信公众号查询详情。

这张图显示的是“账号连接已断开”的通用提示。它与此前的 ACE 提示分别记录，目前不能确认两者是同一个原因，也不能只凭这张图判断账号被冻结。

## 我让 GPT / Codex 做过什么

- **整理排查任务**：让 GPT 把需要检查的项目写成详细提示词，再交给 Codex 检查本机。
- **检查 ACE**：核实服务、驱动注册、文件路径、版本、签名、权限和游戏内组件副本。
- **检查系统变化**：读取 Windows 事件、可靠性记录、更新记录和近期软件、驱动变化。
- **检查软件影响**：查看火绒、System Informer、远程软件、输入法、Steam++、Clash 等相关线索。
- **检查网络环境**：查看系统代理、WinHTTP、DNS、hosts、TUN、路由和网络过滤组件。
- **整理诊断材料**：生成诊断报告、只读状态快照脚本，备份 8 项 ACE 注册配置，并核验官方卸载程序。
- **调整代理分流**：在后续网络配置任务中兼顾国内游戏直连，生成覆写脚本、配置备份和一键恢复工具；游戏实战效果没有验证。

## 排查发现了什么

| 发现 | 可以说明什么 | 尚不能说明什么 |
| --- | --- | --- |
| 85 个已检查的 ACE 二进制签名有效 | 这些文件未发现签名失效 | 不代表 ACE 全部运行正常或没有缺失组件 |
| 两项 ACE 驱动注册指向缺失文件 | 存在失效的注册引用 | 尚不能确认是当前游戏必需的组件，也不能直接归因到处罚 |
| 游戏退出后的快照中，三项 ACE 驱动保留 Win32 退出码 31 | 需要比较运行前后的状态 | 不是已经确认的 ACE 处罚原因码；Stopped 本身也不等于异常 |
| Steam++ 的历史日志出现腾讯安全相关请求经过反向代理的记录 | 有代理介入的具体线索 | 没有证明请求失败、ACE 心跳失败或因此处罚 |
| 可读日志未找到 ACE 崩溃或火绒拦截的直接证据 | 当前没有相应的直接证据 | 不能据此排除全部运行时问题或历史拦截 |
| ARAMKit 在首次报错后才安装 | 不能解释首次故障 | 不等于已经完成所有后续兼容性验证 |

目前优先核实的是代理链与 ACE 驱动状态。雷电模拟器长期存在，未发现能把它列为主要原因的近期变化或直接证据。
