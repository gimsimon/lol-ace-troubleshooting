# 给 Codex 的只读诊断提示词

下面是根据本案例整理的通用版本。使用前应把背景替换成自己的情况；不要把未执行的操作写成已完成。

```text
请作为 Windows 故障排查工程师，对我的电脑进行只读诊断，分析英雄联盟国服出现 ACE 异常、账号断连或短时限制的原因。

背景：
- Windows 10，通过 WeGame 启动。
- 此前长期正常，最近开始在游戏运行一段时间后提示“安全系统或数据被篡改”，并出现 5 分钟限制。
- 另有“这个账号的连接已断开”的截图。请分别记录两类提示，不要默认它们具有相同根因。
- 已做过 WeGame 普通修复、深度修复及游戏重装，未解决。
- 清理 DNS 后似乎短暂恢复，但因果关系不确定。
- 首次报错日期、准确时间和当时运行的软件：由我补充；缺少的信息请明确标注。

检查范围：
1. ACE / SGuard 服务和驱动的注册配置、文件路径、版本、签名、权限及近期变化。
2. System、Application、Code Integrity、可靠性记录和可访问的相关事件，优先分析报错前后 10 分钟。
3. 最近 14～30 天的 Windows、软件和驱动变化，区分“安装存在”“正在运行”“有实际冲突证据”。
4. 可读取的安全软件拦截 / 隔离记录，以及针对 ACE 的进程限制配置和计划任务。
5. 系统代理、WinHTTP、DNS、hosts、TUN、路由及网络过滤组件；分别记录现在的状态和能够确认的历史状态。
6. 分析清理 DNS 后短暂恢复是否有证据支持，不要直接把 DNS 当成根因。

判断要求：
- 游戏退出时服务 / 驱动 Stopped 不一定异常。
- 区分通用 Win32 退出码、设备管理器错误码和厂商处罚码。
- 文件签名有效不等于全部组件完整或运行正常。
- 日志告警、时间接近、某软件已安装，都不自动构成因果证明。
- 不因为长期存在的模拟器、远控软件或其他工具存在，就直接认定冲突。
- 没有日志输出时，说明查询范围、权限和保留期，不要直接认定正常。

执行范围：
- 只允许读取和分析，以及向当前任务的本地工作目录写诊断材料。
- 不启动游戏、不进入对局、不主动复现处罚。
- 不结束进程、不停止服务、不强行加载驱动。
- 不删除、覆盖或修改游戏文件、ACE 文件、注册表、安全设置或网络配置。
- 不关闭防护、不改防火墙、不添加白名单、不做网络重置。
- 不使用隐藏、修改或绕过反作弊的方式测试。
- 不读取账号凭据、Cookie、Token；不上传个人文件、原始日志或代理凭据。
- 遇到权限不足时记录并继续其他检查；如需扩大权限，说明具体用途。

输出：
- 已确认的检查结果和证据。
- 异常及时间，区分观察事实、合理怀疑和确认根因。
- 最优先的排查方向，列出支持证据、反对证据及缺少的信息。
- 从低风险到高风险的后续建议，并标明哪些尚未执行。
- 生成本地 Markdown 诊断报告；另给一份可以公开的脱敏摘要。

请自动完成获准的只读检查，不要重复已经完成且状态未变化的简单查询。
```
